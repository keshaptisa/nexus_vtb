# Старт · команда nexus

Молодёжный раздел мобильного банка для 14–22 лет (концепт для ВТБ Онлайн).
Банк **перехватывает перевод**, когда подростка используют как «дропа», и помогает **безопасно выйти** из ситуации, если чужие деньги уже пришли. Вокруг — финграмотность через реальные действия.

Конкурс «Академия Финтеха 2026», трек «Финтех без границ: банк будущего для бизнеса и клиентов».

## Быстрый старт

```bash
cp .env.example .env
docker compose up --build
```

- Сайт: http://localhost:5173 — выбор аккаунта (Артём, Дима, Катя, Соня, Лев) → личный кабинет
- API и Swagger: http://localhost:8000/docs
- Распознавание скриншотов в Щите (по желанию, +1 ГБ): `WITH_OCR=1 docker compose up --build`
- Локальная LLM для ассистента и Щита (по желанию): `docker compose --profile llm up`, затем в `.env` поставить `LLM_PROVIDER=ollama`
- Российская модель GigaChat вместо on-prem: `LLM_PROVIDER=gigachat` и `GIGACHAT_CREDENTIALS=<ключ авторизации>` в `.env`
- Прямая ссылка на сторис: `http://localhost:5173/u/artem?story=0`

### Без Docker

```bash
# backend
cd backend && python -m venv .venv && .venv/Scripts/activate && pip install -r requirements.txt
pip install -r requirements-ocr.txt     # по желанию: проверка скриншотов (EasyOCR, ~1 ГБ)
uvicorn app.main:app --reload            # http://127.0.0.1:8000
pytest -q

# frontend (в другом терминале)
cd frontend && npm install && npm run dev   # http://localhost:5173, /api проксируется на бэкенд
```

## Как показывать

1. Выберите аккаунт → в кабинете нажмите **«Проиграть сценарий»**.
2. Справа выезжает панель: переписка с вербовщиком (сообщения приходят с «печатает…»), шаги и **«Что видит банк»** — риск и сигналы меняются вживую.
3. На событиях сверху появляется **пуш**, затем **окно банка** с действиями. Сценарий ждёт решения; «Пропустить шаг» — если нужно быстрее.
4. В конце — итог с XP и предложение пройти квест.

| Сценарий | Что показываем |
|---|---|
| `artem` — Артём, 16 | +30 000 ₽ от незнакомца → окно «Необычное зачисление» (можно сразу «Вернуть через банк») → просьба переслать 27 000 ₽ → **перехват** (CatBoost, причины из SHAP) → «Безопасный выход», ветка A → итог |
| `dima` — Дима, 17 | Банк заметил вчерашний транзит → угрозы вербовщика → окно «Вам угрожают» → ветка B: пауза, банк, полиция → итог |
| `katya` — Катя, 19 | Первая зарплата, третья подписка, перерасход на доставку → окно и сторис на каждое событие, 10% зарплаты — в копилку → XP |
| `sonya` — Соня, 13 → 14 | **Мост:** «Детский банк» → «Старт» в одно касание с согласием мамы; цели, копилка и XP переносятся; первая история — про свою карту |
| `lev` — Лев, 15 | **«Пушкинская карта»:** витрина «Старта» → карта «Старт» за минуту → первое пополнение → первая цель в копилке |

Без сценария в кабинете всё работает вручную: **пополнить** (мама, папа или незнакомец — алгоритм сравнит с обычным поведением), **перевести**, **оплатить**, **проверить сообщение** (текст или скриншот), **сторис** и **квест**, **профиль** с уровнем и бейджами, ассистент **Бит** в углу.

## Структура

```
backend/    FastAPI: движок сценариев, фейковый банк, скоринг (CatBoost), Щит (TF-IDF + логрег + признаки схемы, OCR),
            «Безопасный выход», сторис и XP, ассистент
frontend/   React + Vite + TS + Tailwind: / — выбор аккаунта, /u/:id — кабинет со сценарием
mobile/     приложение на Expo без бэкенда: модели и сценарии считаются на телефоне (mobile/README.md)
ml/         генераторы синтетики, обучение моделей, метрики
content/    сценарии, персонажи, юр. тексты с источниками, ветки SOS, уроки, квест
docs/       PLAN.md — план, TASKS.md — кто что делает, api.md — контракты, research/ — исследование
```

## Как устроен алгоритм

- **Этап 1 — зачисление.** Сравниваем с профилем клиента: свои отправители, средний чек пополнения. Деньги от незнакомца в разы больше обычного — помечаются «под проверкой», банк предупреждает (но не блокирует: запретить получить деньги нельзя).
- **Этап 2 — перевод.** CatBoost команды (`backend/app/ml/`) оценивает транзит: сколько пришло от незнакомцев, какую долю пересылают, как быстро. От 0.7 — перевод останавливается, причины — из SHAP и профиля.
- **Щит.** Классификатор сообщений + группы признаков схемы («пришлют деньги», «перешли дальше», «процент», «карта»). Скриншот → EasyOCR → та же проверка.
- **LLM только объясняет.** Решения принимают модели; без LLM работают шаблоны.
- Метрики моделей: [ml/reports/metrics.md](ml/reports/metrics.md). Все данные синтетические. Состояние банка (операции, XP, цели, доказательства) сохраняется в PostgreSQL и переживает перезапуск; без базы бэкенд работает в памяти. Сбросить аккаунт — кнопка «сначала» в кабинете.

## Правила репозитория

- `main` — только рабочий код; фичи в `feat/...`, мерж через PR с ревью.
- Перед каждым дедлайном — тег `sprint-1` / `sprint-2` / `sprint-3`, на платформу сдаём **ссылку на тег**: менять материалы после дедлайна нельзя (п. 5.9.2 Правил).
- Никаких реальных персональных данных. Юридические тексты — только из `content/legal.json` со ссылкой на источник.
- Логотип и фирменный стиль ВТБ не используем без письменного разрешения организаторов.
