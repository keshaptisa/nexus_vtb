# «Старт» — молодёжный раздел ВТБ Онлайн, который не даёт подросткам стать дропами

Банк **останавливает перевод**, когда через карту подростка пытаются провести чужие деньги, **объясняет**, что
происходит и чем это грозит, и помогает **безопасно выйти** из ситуации, если деньги уже пришли. Вокруг —
финграмотность по реальным событиям и мост «Детский банк» → «Старт» → взрослый ВТБ.

## Проблема

- **Больше половины** людей в базе дропов Банка России моложе 25 лет; у ВТБ доля дропов 14–17 лет за I квартал
  2026 года выросла **в 4 раза** (по данным СМИ).
- С июля 2025 года дропперство — **уголовная статья** (ст. 187 УК, с 16 лет).
- Банки обязаны останавливать подозрительные переводы, но делают это стандартным окном без объяснений —
  жалоб в ЦБ на блокировки стало **в 6 раз больше**, чем в 2023 году.
- Наш опрос (n = 231, 18–22 года): **37%** получали предложения «подработки» через карту, у **73%** из них первое —
  до 18 лет; если на карту пришли чужие деньги, позвонить в банк выбирает только **51%**.

Детские банковские продукты заканчиваются в 14 лет — ровно тогда, когда начинается вербовка.

## Решение

| | Что делает |
|---|---|
| **Перехват с объяснением** | Вместо «операция отклонена» — «похоже, через вашу карту хотят провести чужие деньги»: причины, последствия и кнопки «отменить», «мне предложили подработку», «позвонить в банк» |
| **«Безопасный выход»** | Деньги уже пришли — вернуть через банк в одно касание, сохранить переписку, получить черновик обращения. Четыре ветки: пришли, уже переслал, отдал карту, заблокировали |
| **Щит** | Проверка подозрительного сообщения или скриншота: вербовка, другое мошенничество или норма |
| **Финграмотность по событию** | Первая зарплата — история про НДФЛ, перевод от незнакомца — квест «А что было бы, если…», копилка и цели |
| **Мост и каналы роста** | «Детский банк» → «Старт» в 14 лет в одно касание (цели, копилка и опыт сохраняются); витрина для держателей «Пушкинской карты» |

## Демо

Запустите проект локально (см. «Быстрый старт») → http://localhost:5173 → выбрать героя → в кабинете нажать **«Проиграть сценарий»**. Справа — переписка с
вербовщиком, шаги сценария и панель **«Что видит банк»**: оценка риска и её причины меняются вживую.

| Герой | Сценарий |
|---|---|
| Артём, 16 | +30 000 ₽ от незнакомца → просьба переслать 27 000 ₽ → **перехват** → «Безопасный выход» → деньги заморожены для возврата |
| Дима, 17 | Деньги уже переслал, вербовщик угрожает → пауза, обращение в банк и полицию |
| Катя, 19 | Первая зарплата, подписки, перерасход → истории по событию, 10% в копилку |
| Соня, 13 → 14 | Переход из «Детского банка» в «Старт» с согласием родителя |
| Лев, 15 | «Пушкинская карта» → карта «Старт» → первая цель; предупреждение о схеме «выкупа» |

Без сценария всё работает вручную: пополнить (от родителя или незнакомца), перевести, оплатить, проверить сообщение,
пройти истории и квест. Карточка **«Метрики»** показывает метрики продукта по текущей сессии демо.

**Мобильное приложение** на Expo (`mobile/`) повторяет сценарии и считает скоринг и Щит прямо на телефоне, без сервера.

## Ценность и экономика

- **Рынок:** TAM 14,6 млн (молодёжь 14–22), SAM 12,4 млн (с картой), SOM 2,9 млн клиентов ВТБ 14–22.
- **Каналы, которые есть только у ВТБ:** ~110 тыс. выпускников «Детского банка» и ~1,5 млн новых держателей
  «Пушкинской карты» в год.
- **Модель B2B2C:** клиенту бесплатно; банк получает меньше дроп-кейсов (~5,6 тыс. ₽ разбор каждого), меньше
  обращений о блокировках, удержание и привлечение молодых клиентов.
- **Финмодель 2027–2031, базовый сценарий:** инвестиции 66,5 млн ₽, NPV +299 млн ₽, окупаемость 23 месяца.

## Метрики

**North Star — предотвращённые транзиты в месяц:** переводы, отменённые после перехвата, плюс деньги, возвращённые
через «Безопасный выход».

A/B-пилот на ~300 тыс. молодых клиентов, 3 месяца. Цели: дроп-кейсы −15%, ложные перехваты ≤ 1% переводов,
отмены после перехвата ≥ 60%, «Я влип» → действие ≥ 50%. Стоп: снижение дроп-кейсов < 8% или ложных перехватов > 2%.

## Как это работает

- **Зачисление.** Сравниваем с профилем клиента: свои отправители, обычные суммы. Деньги от незнакомца в разы больше
  обычного помечаются «под проверкой» — банк предупреждает, но не блокирует.
- **Перевод.** CatBoost оценивает транзит: сколько пришло от незнакомцев, какую долю пересылают, как быстро.
  Выше порога — перевод останавливается, причины берутся из SHAP и профиля клиента.
- **Щит.** TF-IDF + логистическая регрессия + признаки схемы («пришлют деньги», «перешли дальше», «процент»,
  «карта»); скриншот распознаётся через EasyOCR.
- **LLM только объясняет** простым языком (GigaChat или модель в контуре банка). Решения принимают измеримые модели;
  без LLM работают шаблоны.

**Качество на синтетических данных** ([ml/reports/metrics.md](ml/reports/metrics.md)):

| | Значение |
|---|---|
| Скоринг: PR-AUC, правила → CatBoost | 0,70 → 0,998 |
| Ложные перехваты, доля честных переводов | 0,8% |
| Самозанятые с хотя бы одним ложным перехватом за 60 дней, после доработки | 22,4% → 7,5% ([отчёт](ml/reports/self_employed.md)) |
| Щит: точность на 150 сообщениях, написанных вручную | 0,83 |

Данные синтетические: цифры показывают, что подход работает и обходит правила, а не качество на реальных данных банка.

## Быстрый старт

```bash
cp .env.example .env
docker compose up --build
```

- Сайт: http://localhost:5173 · API и Swagger: http://localhost:8000/docs
- Распознавание скриншотов в Щите (+1 ГБ): `WITH_OCR=1 docker compose up --build`
- Локальная LLM: `docker compose --profile llm up`, в `.env` — `LLM_PROVIDER=ollama`
- GigaChat: `LLM_PROVIDER=gigachat` и `GIGACHAT_CREDENTIALS=<ключ>` в `.env`

Без Docker:

```bash
cd backend && python -m venv .venv && .venv/Scripts/activate && pip install -r requirements.txt
uvicorn app.main:app --reload          # http://127.0.0.1:8000
pytest -q                              # 46 автотестов

cd frontend && npm install && npm run dev   # http://localhost:5173
```

Мобильное приложение: `cd mobile && npm install && npx expo start` — подробнее в [mobile/README.md](mobile/README.md).

## Структура

```
backend/    FastAPI: сценарии, банк, скоринг (CatBoost), Щит, «Безопасный выход», истории и XP, метрики, ассистент

docs/       исследование, бизнес-модель, материалы к питчу, API, деплой, видео
```

## Принципы

- Все данные в демо синтетические; реальных персональных данных нет.
- Юридические тексты — только из `content/legal.json`, у каждого утверждения есть источник.
- Решение рассчитано на работу в контуре банка: персональные данные не покидают его (152-ФЗ), перехват дополняет
  антифрод, а не заменяет его.
- Логотип и фирменный стиль ВТБ в продукте не используем без разрешения организаторов.
